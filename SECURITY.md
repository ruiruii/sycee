# Security

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

Older releases are not supported.

## Reporting a vulnerability

Report vulnerabilities in private:

- Email [sycee.rachel@gmail.com](mailto:sycee.rachel@gmail.com).
- GitHub private vulnerability reporting, when that feature is enabled for this repository: <https://github.com/ruiruii/sycee/security/advisories/new>.

Include the affected version, a description of the issue, and a way to reproduce it. Do not open a public GitHub issue for an undisclosed vulnerability.

## Response

We will acknowledge a report within 5 business days. There is no hard response or fix SLA beyond that acknowledgement.

## Scope

In scope: the specification (`SPEC.md` and the VSR schema) and the signing and verification code in the `@sycee/*` packages.

SYCEE does no custody, no fund movement, and no scoring. Reports about those activities are out of scope.
